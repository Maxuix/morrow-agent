## 故障与迁移矩阵

| 切点 | 必须证明 |
|---|---|
| 接纳后 HTTP 丢失 | 同键查询/重试返回同一提交，不额外执行 |
| 用户已提交/模型未完成 | 显示正确活动/失败/恢复状态，未完成尾部不当作成功 |
| 工具已执行/结果未确定 | 遵守既有 unknown outcome/Recovery，不盲重试副作用 |
| 审批已决定/唤醒中断 | durable 决定与运行恢复一致，不重复授权/执行 |
| Session/Workspace 切换 | 旧响应不覆盖新视图，不串用文件/设置/审批 |
| 附件已上传/消息尚未提交 | 无引用草稿可清理；已提交引用不可误删 |
| 迁移/备份/恢复中断 | 不产生无声部分升级；旧状态可从匹配备份恢复 |
| 实时流缓冲溢出 | resync 与已提交水位一致，Agent 不被慢客户端阻塞 |
