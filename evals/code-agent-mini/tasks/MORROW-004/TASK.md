# 持久化 Preference Writer 的恢复状态

Preference Writer 采用准备、发布和最终确认的持久化写入流程。当恢复期间无法读取 YAML 权威文件，或发布后无法重新读取进行验证时，当前实现只抛出异常，没有把该批次持久化为需要人工解决的状态。进程重启后因此可能丢失关键恢复事实。

请修复这一问题，并同时检查请求边界：

- 恢复读取失败时，将批次保存为 `NEEDS_RESOLUTION`，并记录稳定的恢复代码；
- 发布后验证读取失败时同样持久化对应恢复状态；
- 非法 scope、revision、command ID 和操作类型应转化为稳定的领域错误；
- command ID 并发重复写入时，相同请求应返回既有准备结果，不同请求应报告冲突；
- 不得把损坏的 YAML 当作空配置覆盖，也不得绕过现有 Saga 所有权。

完成后运行 Preference Writer 的针对性测试。
